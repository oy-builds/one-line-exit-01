# The One-Line Exit

A make.fun entry for "The One-Line Exit": one funny single-line resignation
letter, from a night-shift lighthouse keeper whose lamp has been automated,
whose gulls have unionized, and who has decided to join them.

`main.ts` (Node 22, standard library only) writes the letter to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> I hereby resign as night-shift lighthouse keeper: the lamp is automated, the gulls have unionized, and frankly, so have I.

Run it with `node main.ts`.
